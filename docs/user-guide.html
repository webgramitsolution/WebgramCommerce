Getting started

Webgram is two products: Webgram Theme (design, header and footer builders, mega menu, shop and product layouts, slide cart) and Webgram Core (features: reviews, wishlist, compare, quick view, badges, coupons, slider, reels, Instagram, voice search, AI assistant, invoices, branded emails, WhatsApp notifications, analytics, site tools). The theme works on its own; Core adds the features and works with any theme.

RequirementVersion
WordPress6.4 or newer
WooCommerce8.5 or newer (optional for the theme, required for most Core modules)
PHP8.1 to 8.4
ElementorOptional. Every section is also a Gutenberg block and a shortcode.

Install theme and Core

  1. Appearance > Themes > Add New > Upload Theme: choose webgram-theme.zip, install, activate.
  2. Go to Webgram > System status. Click Install Webgram Core. The theme installs the plugin from its bundled copy and activates it. No external download.
  3. Install WooCommerce if it is not present and finish its setup wizard.
  4. Open Webgram > Modules and switch on the modules you need. Disabled modules load nothing on the frontend.
If you update the theme later and the new version bundles a newer Core, System status shows Update bundled Webgram Core. Click it to update in place. You can also upload webgram-core.zip through Plugins > Add New at any time.

Demo import

Webgram > Demo import reproduces the preview store. Tick the parts you want and click Import. Steps run in order: theme settings and builder presets, placeholder images, sample products and categories, blog posts, Webgram Core content (home slider, testimonials, coupons, wishlist and compare pages), pages (Home, Blog, Help, Track Order, Bulk Order, About, Contact), menus and footer widgets. Nothing you already have is deleted; running it twice reuses what exists.

The placeholder images are flat coloured shapes: replace them with your own product photos under Products and Media.

Child theme

Activate webgram-child.zip when you plan to edit template files or add PHP. Put CSS in the child style.css and template overrides at the same path as in the parent (for example webgram-child/woocommerce/content-product.php). Core templates can be overridden at webgram-child/webgram-core/{module}/{name}.php.

When Webgram Core is active, its feature tabs appear in the same panel (Reviews, Wishlist, Compare, Invoice, Notifications, and so on). The Customizer keeps only Site Identity.

Import / Export (Webgram > Import / Export) downloads a JSON file with theme settings, header and footer layouts and Core settings, and imports the same file on another site.

Header and footer builders

Webgram > Header Builder: three rows (top, main, bottom) with left, center and right areas, separate layouts for desktop and mobile. Drag elements into areas: logo, menus, search, cart, account, wishlist, compare, deliver to, contact, social, HTML, button, marquee. Each element has its own settings (click the gear). Presets replace the layout in one click: Store, Classic, Minimal, Two row, Centered. Sticky settings apply per row.

Webgram > Footer Builder: a widgets row (2 to 6 columns, first column wide option) and a bottom bar with left, center, right areas. Elements: logo, description, menus, social, contact, payment icons, copyright, HTML, newsletter. Widget areas footer-1 to footer-6 accept normal WordPress widgets too.

Mega menu

Appearance > Menus: each top level item gets Webgram fields: mega menu on or off, columns, column width, icon, badge text, featured image, description, and an HTML block per column (choose an HTML Block created under Webgram > HTML Blocks). Child items become column groups. The mobile drawer shows the same menu with expandable groups and a Categories tab.

Homepage sections

Every section from the demo homepage exists as an Elementor widget (Webgram category), a Gutenberg block (Webgram category) and a shortcode [webgram_{section}]: slider, marquee strip, category circles, trending products, mega saver, best sellers band, reels row, about, blog grid, testimonials, Instagram feed, benefits row, coupons row, trust badges, section heading, banner. Product sections choose a source (trending, best selling, on sale, featured, top rated, recent, category, tag, specific ids) and a layout (grid, slider, band).

The demo homepage lives in demo/homepage-gutenberg.html (paste in the code editor) and demo/homepage-elementor.json (Templates > Import). Sync tokens to Elementor on the System status page writes your brand colours and fonts into the Elementor kit.

Shop, product, cart, checkout

  • Product card: wave badge, hover slideshow, variant swatches that change price and add to cart, wishlist, compare and quick view actions, buy now. Styles: default, compact, list.
  • Product page: sticky gallery with thumbnails and video, rating pill, coupon box, payment strip, trust seals, contact seller cards, delivery check by pincode, info cards, specifications table, section order from Theme Settings, mobile sticky add to cart bar.
  • Slide cart: opens on add to cart, savings line, offer progress (free shipping threshold and milestones), recommendations, coupon form, updates without reload.
  • Checkout: steps indicator, order summary with coupon, trust info, WhatsApp consent checkbox (when Notifications is connected). Works with the standard WooCommerce checkout and payment gateways.
  • Thank you page: order timeline, invoice download, track link.
  • My Account: icon navigation, dashboard cards, split login and register with inline validation, invoice download per order, WhatsApp updates toggle.
  • Help, Track Order, Bulk Order page templates: assign them under Page Attributes.

Webgram Core modules

Webgram > Modules lists every module with a switch. Settings for each live in Webgram > Settings (or the theme panel tabs when Webgram Theme is active).

Reviews, wishlist, compare

  • Reviews: rating summary with distribution bars, sort and star filters, load more, photo and video uploads (held private until approval), helpful votes, recommendation, review title. Media column and bulk approve in Comments. Stands down automatically when Judge.me, YITH Reviews or Customer Reviews is active. Shortcode [webgram_reviews].
  • Wishlist: guest lists in a signed cookie, merged into the account on login. Header icon with count, card and product buttons, page with share link ([webgram_wishlist]). Create the page from the notice or Demo import.
  • Compare: up to 4 products, floating compare bar, page with sticky first column and difference highlighting ([webgram_compare]).
  • Quick view, Badges (rules: new, sale percent, best seller, low stock, sold out, plus a custom badge per product) and Coupons (product coupon box with copy, cart offer progress) each have a settings tab.

Slider, reels, Instagram

  • Sliders (Webgram > Sliders): slides with desktop, tablet and mobile images, heading, subheading, text, two buttons, overlay, text colour, animation and up to four benefit lines. Slider settings: autoplay, delay, loop, arrows, dots, ratio per device, fade or slide, full width. Insert with the Slider widget, block or [webgram_slider id="123"].
  • Reels (Webgram > Reels): upload an MP4 or paste a YouTube Shorts, Vimeo, Cloudflare Stream or Bunny URL, poster image, up to five products, call to action. The row shows 9:16 cards with muted autoplay; the viewer swipes between reels with a product sheet and add to cart. Categories group reels for the widget.
  • Instagram: connect through the Instagram Graph API (app id, secret, access token; token is encrypted and refreshed monthly) or use manual images. Grid or slider, count, columns, Follow button.

AI assistant and voice search

The AI Shopping Assistant works without any API key in rule based mode (search, best sellers, coupons, order status, store info). To use a model, pick a provider (Anthropic, OpenAI or Gemini), paste the API key (stored encrypted), choose the model, set the per minute limit and the daily budget. The launcher loads the chat only on first click. Conversations are kept for the retention period and are included in WordPress privacy export and erase. Order status is available only to the logged in customer who owns the order.

Voice search adds a microphone to the search box and the assistant using the browser's speech recognition (Chrome, Edge, Safari). Choose the language and whether to submit automatically. Nothing is sent to a server by Webgram; the browser handles recognition.

Invoices and emails

Invoice: store details (logo, legal name, address, GSTIN, PAN, support line), numbering (prefix, padding, financial year, yearly restart), when to generate (payment complete, processing or completed, manual), layout options and colours. PDF through dompdf (bundled) with an HTML fallback. Customers download from My Account and the thank you page; managers from the order screen, or in bulk as a zip. Files are stored under uploads/webgram-invoices/ and served only through a protected endpoint. An HSN field appears in the product Webgram panel when the HSN column is on.

Emails: branded header, footer and styles for every WooCommerce email (logo, colours, button style, footer text, social links), a preview page with test send, and invoice attachments per email type. Sending stays with WordPress wp_mail(): install any SMTP plugin for delivery.

WhatsApp notifications

  1. Create a Meta Business app with the WhatsApp product, add a phone number and get the Phone Number ID, WhatsApp Business Account ID and a permanent access token.
  2. Webgram > Settings > Notifications: paste the three values, click Test connection. Status turns CONNECTED.
  3. Create message templates in Meta Business Manager using the texts in webgram-core/docs/whatsapp-templates.md, wait for approval, click Sync templates.
  4. Map each event (order placed, payment successful, processing, shipped, out for delivery, delivered, cancelled, failed, refunded) to a template and the parameter order. Optionally attach the invoice PDF as the document header.
  5. Paste the webhook URL and verify token into the Meta app to receive delivered and read states.

Customers opt in at checkout or in My Account; no message is sent without consent. Messages go from your own Meta account and any charges are billed by Meta to you. Webgram does not relay or bill messages. Email channel: the same event matrix enables or disables WooCommerce emails and adds Shipped and Out for delivery emails. Webgram > Notifications log shows every attempt with retry and resend.

Analytics

First party events (product views, reel plays, assistant conversations, wishlist and compare adds, WhatsApp delivery) stored in your database without IP addresses. Webgram > Analytics shows cards, 7 or 30 day bars, top reels and products. Sampling, staff tracking and retention are settings. Trending product sections use these views.

Site tools

HTML Blocks (reusable content for header, footer, mega menu and layouts), Layouts (hook a block into a position with conditions), promo popup, cookie notice, age verification, maintenance and coming soon modes, white label (rename the Webgram menu and hide branding), custom JS (only for users with unfiltered_html), optional portfolio post type.

Translation and RTL

POT files: webgram-theme/languages/webgram.pot and webgram-core/languages/webgram-core.pot. Create translations with Loco Translate or Poedit and place them in wp-content/languages/themes/webgram-{locale}.mo and wp-content/languages/plugins/webgram-core-{locale}.mo. wpml-config.xml in both products tells WPML and Polylang which options and post types to translate. RTL stylesheets load automatically for RTL languages.

Performance

  • Each page loads only the stylesheets and scripts it renders; disabled modules load nothing.
  • Use a caching plugin (WP Rocket, LiteSpeed Cache) and Redis object cache on the server. Cart, wishlist and compare counts update through fragments, so full page cache is safe.
  • Host fonts locally from Theme Settings > Performance to avoid a third party request.
  • Serve WebP images (WooCommerce 8.5+ supports it) and keep slider images under 300 KB per device.

Updates

Upload the new theme zip through Appearance > Themes > Add New > Upload (WordPress replaces the current version) or use the marketplace update plugin. Then open Webgram > System status and click Update bundled Webgram Core if offered. Settings, layouts and Core data are kept. Custom code belongs in the child theme so updates never overwrite it. Core runs its database migrations automatically on the first admin visit after an update; back up before major updates.

FAQ

The Webgram menu is missing. The theme is not active or your user lacks edit_theme_options.

Core tabs do not show in Theme Settings. Enable the module under Webgram > Modules; only enabled modules register tabs.

Invoices download as HTML, not PDF. The Core folder is missing vendor/ (dompdf). Reinstall from the packaged zip or run composer install --no-dev in the plugin folder.

The microphone does not appear. The browser has no speech recognition (Firefox) or the page is not served over HTTPS.

WhatsApp messages stay queued. WP cron is not running. Set up a system cron (see the deployment guide) or install WP Crontrol to check.

Wishlist page shows nothing. Set the page containing [webgram_wishlist] in Webgram > Settings > Wishlist or click the notice to create it.

Header changes do not appear. Clear the page cache; the builder saves immediately but cached pages keep the old HTML.

Developers

Hooks: see hooks-reference.md (generated from the source). Theme hooks follow webgram/area/event, Core hooks webgram_core/module/event. Templates: Core templates in webgram-core/templates/ can be copied to {theme}/webgram-core/{path}. Theme parts receive an $args array. REST namespace webgram/v1; WC-AJAX actions are prefixed webgram_ and require the nonce found in the WebgramCore JS object. Check module state from a theme with webgram_has_core( 'wishlist' ). Source SCSS and ES modules are in the repository under webgram-theme/assets/src; build with npm install && npm run build.

Deployment on a Linux VPS with Nginx, PHP-FPM and Redis, including the rule that protects invoice files: deploy-hostinger.md.
